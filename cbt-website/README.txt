CBT PRO - HTML/CSS/JavaScript CBT WEBSITE

HOW TO RUN:
1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open index.html in a browser.
4. Enter a student name, class and subject.
5. Click Start Examination.

FILES:
index.html       Login/start page
exam.html        Examination page
result.html      Result page
css/style.css    Responsive design
js/questions.js  Questions and correct answers
js/exam.js       Timer, navigation, answers and scoring
js/result.js     Result display

NOTE:
This is the frontend version. It stores the current examination in browser localStorage.
The next stage can connect this system to PHP + MySQL for student accounts, an admin panel,
database questions, classes, subjects, results and examination history.
